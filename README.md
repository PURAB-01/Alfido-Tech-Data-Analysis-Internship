# Alfido Tech - Data Analytics Internship

This repository contains completed data analysis tasks for the 1-Month Data Analytics Internship at Alfido Tech.

## Task Overview

### Task 1: Customer Behavior Analysis
- **Goal**: Segment users using RFM modeling and evaluate purchase behavior.
- **Key Outcome**: Identified 4 key segments and provided 5 actionable retention strategies.

### Task 2: Sales Performance Analysis
- **Goal**: Analyze revenue, profit margins, and regional sales trends.
- **Key Outcome**: Calculated core KPIs and identified category discounting risks.

### Task 3: Website Traffic Analysis
- **Goal**: Evaluate session lengths, bounce rates, and user entry points.
- **Key Outcome**: Pinpointed high bounce landing pages and proposed 5 UX conversion optimizations.
